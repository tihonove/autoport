# autoport

Пробрасывает локальные порты на удалённые машины — тогда, когда ты в них упёрся.

Пошёл на `http://localhost:3000/`, а там пусто? Расширение ловит
`ERR_CONNECTION_REFUSED` и уводит вкладку на страницу выбора: на какую машину
пробросить и насколько. Выбрал — `ssh -L` поднят, вкладка вернулась на исходный URL.

Смысл в том, что решение принимается **в момент обращения**. Не нужно ни правил,
ни угадывания контекста: в рабочее время выберешь один хост, дома другой,
для одноразового SSO-каллбэка на случайном порту — третий, с TTL в пять минут.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/tihonove/autoport/main/install.sh | bash
```

Ставит бинарь в `~/.local/bin`, расширение в `~/.local/share/autoport/extension`,
поднимает `systemd --user` юнит и печатает, что доделать руками. Root не нужен.

Дальше один шаг вручную: `chrome://extensions` → «Режим разработчика» →
«Загрузить распакованное расширение» → указать напечатанный путь.

Смотрелка — на http://127.0.0.1:8777/

## Что умеет

- **Проброс по требованию** — из страницы выбора, куда уводит расширение.
- **Проброс руками** — форма в смотрелке, хосты подтягиваются из `~/.ssh/config`.
- **TTL** — 5 минут, час или навсегда. Протухшие снимаются сами.
- **Смотрелка** — что сейчас проброшено, куда, сколько осталось, кнопка «снять».
- **Домены на localhost** — если `foo.example.com` смаплен в `/etc/hosts` на `127.0.0.1`,
  добавь его в `WATCH` в `extension/background.js` **и** в `host_permissions` манифеста.
  Забыть второе — событий не будет, и молча.

## Как устроено

**Одно ssh-соединение на хост, пробросы вешаются на живое:**

```
ssh -N -M -S <sock> <host>                                     мастер
ssh -O forward -L 127.0.0.1:3000:localhost:3000 -S <sock> <host>
ssh -O cancel  -L 127.0.0.1:3000:localhost:3000 -S <sock> <host>
```

Так, а не `ssh -N -L` на каждый проброс, потому что иначе каждый новый проброс —
это новая аутентификация. С Tailscale SSH, который периодически просит подтвердить
сессию в браузере, это принципиально. Ссылку `To authenticate, visit: …` сервис
вылавливает из stderr и показывает плашкой с кнопкой «Проверить».

Соединение закрывается само, когда на нём не остаётся пробросов.

**Пробросы живут, пока жив сервис.** Состояние никуда не пишется, поэтому не бывает
рассинхрона «в файле записано, а туннеля нет». Перезапуск гасит всё.

**Порт 443.** `ssh` под юзером не биндит порты ниже 1024. Разово, под root:

```bash
echo 'net.ipv4.ip_unprivileged_port_start = 443' | sudo tee /etc/sysctl.d/50-autoport.conf
sudo sysctl --system
```

Побочка: 443–1023 станут доступны всем процессам машины. Ручка одна на IPv4 и IPv6.

## Безопасность

До `127.0.0.1:8777` достучится любая открытая вкладка, а действия тут поднимают
ssh-туннели. На всех мутациях три слоя:

- `Sec-Fetch-Site` должен быть `same-origin` — заголовок ставит браузер, со страницы
  его не подделать;
- `Origin`, если пришёл, должен совпадать с нашим хостом;
- CSRF-токен в форме — ловит всё остальное, включая `curl`.

Имя хоста уезжает в аргументы `ssh`, поэтому принимается только то, что описано
в `~/.ssh/config`. Возвратный URL пропускается только со схемой `http`/`https`.

Расширение просит права **только** на localhost и явно перечисленные домены —
остального браузинга оно не видит.

## Сборка

Go на хосте не нужен, тулчейн живёт в контейнере:

```bash
./build/build.sh          # → bin/autoport
./build/build.sh vet
./build/build.sh fmt      # пусто = всё отформатировано
```

Сборка идёт под `--user $(id -u)`, иначе артефакты и кэш лягут под root.
Кэш — в `~/.cache/autoport-build`.

Релиз собирается по тегу `vX.Y.Z`: бинари под x86_64 и arm64 (чистый stdlib,
CGO не нужен), архивы с бинарём и расширением уезжают в GitHub Release —
оттуда их и берёт `install.sh`.

```
extension/          MV3-расширение: ловит падение, уводит вкладку
cmd/autoport/       точка входа
internal/fwd/       ssh-мастера, пробросы, TTL
internal/sshconf/   разбор ~/.ssh/config
internal/web/       смотрелка и страница выбора
```

## Грабли

- **`ControlPersist` уводит ssh в фон**: родитель выходит с `rc=0`, мастер становится
  неуправляемым. Поэтому явный `-o ControlPersist=no`.
- **`pkill -f autoport` убивает сам себя** — строка поиска попадает в командную строку
  собственного шелла. Гасить по PID: `ss -ltnpH 'sport = :8777'`.
- **Порт в фильтре `urls` расширения молча игнорируется** — все порты матчатся всегда,
  фильтровать по порту можно только в JS.
- **`chrome-error://chromewebdata` не скриптуется** — вклиниться в страницу ошибки
  Chrome нельзя в принципе, только увести вкладку.
